# Gruvbox Remastered GTK Theme

Gruvbox Remastered is a modern, refined take on the classic Gruvbox color palette for GTK-based Linux desktops.  
Designed for comfort, readability, and aesthetic consistency across your GTK3 and GTK4 applications.

---

## Features

- Enhanced contrast and color balance for all GTK applications  
- Clean, modern look for windows, buttons, and controls  
- Full support for GTK3 & GTK4  
- Dark and Light variants included  
- Compatible with GNOME Shell, Cinnamon, and other GTK environments
